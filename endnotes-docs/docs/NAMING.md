# Naming

## Product name

**Endnotes**

## Tagline options

- Beautiful references for React.
- References that look like they belong.
- A trust layer for modern interfaces.
- Citations that inherit your product’s style.
- Source trails for modern products.

## Positioning

Endnotes is not a bibliography tool.

Endnotes is a trust UI primitive.

## Language

Use:

- references
- sources
- notes
- evidence trails
- source previews
- claims
- trust layer

Avoid leading with:

- bibliography
- academic citations
- MLA
- APA
- citation manager
- research paper formatting

## One-liner

Endnotes is a tiny React API for adding beautiful references, source previews, and endnote sections that inherit your app’s style.
