# Endnotes Design Principles

## 1) Small beats broad

Endnotes stays focused on one job: clean source trails for modern interfaces.

## 2) Native over branded

Defaults should inherit host typography, colors, borders, and radius.

## 3) Quiet markers, clear evidence

Inline markers support reading flow; generated notes carry the detail.

## 4) Useful metadata by default

A note should explain what supports a claim, not just link away.

## 5) Deterministic behavior

Numbering and dedupe should be stable and predictable.

## 6) Accessibility is baseline

Keyboard navigation, focus visibility, and reduced-motion support are required.

## 7) No academic baggage

Endnotes is not a bibliography manager. It is a product UI primitive.
